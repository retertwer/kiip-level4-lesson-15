សរុប 30 សំណួរ

សេចក្តីណែនាំ

  • ដំបូង អ្នកនឹងឃើញតែភាសាកូរ៉េ ដើម្បីសាកល្បងការយល់ន័យដោយខ្លួនឯង។
  • បន្ទាប់ពីឆ្លើយរួច ការបកប្រែខ្មែរ របៀបអាន និងការពន្យល់លម្អិតនឹងបង្ហាញស្វ័យប្រវត្តិ។
  • មានប៊ូតុងជំនួយ: បកប្រែសំណួរ, កាត់ 50/50, បកប្រែចម្លើយ។
  • ប៊ូតុងសម្លេងប្រើ Google TTS ជាមុន ហើយប្ដូរទៅ Web Speech API បើមានបញ្ហា។
